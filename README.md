# Heart Disease Risk Prediction — Bioinformatics Assessment

**Student ID:** 2020/ASP/83
**Module:** Bioinformatics  

## Project Overview

This project applies machine learning to predict the presence of coronary 
artery disease from routine clinical measurements using the Cleveland Heart 
Disease Dataset (UCI Machine Learning Repository, 1988).

## Research Question

Can routine clinical measurements such as cholesterol, resting blood pressure, 
and chest pain type predict the presence of coronary artery disease — and which 
features carry the most diagnostic weight?
